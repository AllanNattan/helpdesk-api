
# HelpDesk API

API REST para gerenciamento de chamados de suporte técnico.

## Objetivos

- Gerenciar usuários e chamados de suporte.
- Implementar autenticação e controle de permissões.
- Registrar o histórico de alterações dos chamados.
- Disponibilizar filtros e paginação.
- Manter testes automatizados e documentação técnica.

## Requisitos

- Python 3.12
- Git

## Ambiente de desenvolvimento

Ative o ambiente virtual:

```bash
source .venv/bin/activate
```

Instale as dependências de desenvolvimento:

```bash
python -m pip install -e ".[dev]"
```

Execute os testes:

```bash
python -m pytest
```
